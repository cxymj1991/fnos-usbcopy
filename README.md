# USB Copy 同步（fn-usbcopy）

为飞牛 fnOS 开发的第三方应用，功能参照群晖 NAS 的 **USB Copy**：当插入**指定的 U 盘**时，自动将其内部**选定文件夹**同步到飞牛 NAS 的**选定文件夹**。

> 纯 Python 标准库实现，运行时不依赖任何额外 pip 包；需要系统提供 `lsblk`、`umount` 等基础命令（fnOS 自带）。

## 功能特性

- **按设备识别 U 盘**：支持按 `UUID` / 卷标 / 序列号 精确识别某一块 U 盘，也支持「任意 U 盘」。
- **可视化选择 U 盘**：新建任务时，直接从「已连接 U 盘」列表**点选当前已插入的设备**自动填充识别条件，无需手动抄写 UUID；也可在「已连接 U 盘」页一键「用此 U 盘新建任务」。
- **多文件夹配对映射**：支持一次配置**多对**「U 盘文件夹 → NAS 文件夹」的映射（仿 FreeFileSync 的左右栏映射），两侧目录均可**可视化浏览选择**，并可添加多对。NAS 侧仅展示「我的文件」：自动识别所有存储空间（`/vol1`、`/vol2`…）下的用户目录并全部列出，不暴露系统其它目录；**网盘 / 远程挂载**（rclone FUSE 挂载的百度网盘、阿里云盘等，以及 SMB/NFS 共享）会被自动排除，只列本地硬盘文件夹。
- **日志记录变更明细**：同步完成后，日志末尾会**集中列出**本次「复制 / 冲突重命名 / 删除（镜像）」的文件明细（最多 500 条），汇总行按「新增 / 更新 / 跳过 / 删除 / 错误」分别统计；可在设置中关闭明细只留汇总。
- **手机推送**：同步完成/失败后，可推送到手机 —— 支持 **PushPlus（微信）**、**SMTP 邮件** 两种渠道（可在设置中多选并「发送测试推送」验证）。飞牛 App 自带通知只显示在 App 内、不进手机通知栏，用本功能即可在手机微信/邮箱收到同步结果。
- **三种复制模式**（同群晖 USB Copy）：
  - **增量**：仅复制新增 / 修改的文件，不删除目标中已有文件。
  - **镜像**：使目标成为源的完整镜像，删除源中已不存在的文件。
  - **多版本**：每次运行在目标下新建以时间命名的子目录，完整备份。
- **文件过滤**：可为每个任务设置「仅包含」与「排除」规则（glob，如 `*.jpg`、`.Trash-1000`）。
- **冲突策略**：同名文件 `覆盖` / `跳过` / `重命名保留两者`。
- **完成后自动弹出 U 盘**。
- **Web 管理界面**：在飞牛桌面以 iframe 打开，可视化创建 / 编辑 / 删除任务、查看已连接 U 盘与运行日志。运行日志页显示最近 1000 条，「查看完整日志」可浏览全部已保存日志或直接下载 `usbcopy.log` 文件。
- **自动检测**：后台线程周期性（默认 5 秒）轮询 `lsblk`，识别可移动 USB 分区及其挂载点、UUID、卷标、序列号。

## 安装

### 方式一：直接下载安装包（推荐）

到 [Releases](https://github.com/cxymj1991/fnos-usbcopy/releases) 页面下载最新的 `fn-usbcopy-<版本>.fpk`，在飞牛「应用中心 → 手动安装 / 上传」中选择安装即可。

### 方式二：使用本仓库 build.sh 生成 fpk 后安装

```bash
cd fn-usbcopy
bash build.sh          # 生成 fn-usbcopy-<版本>.fpk
```

然后在飞牛「应用中心 → 手动安装 / 上传」中选择生成的 `fn-usbcopy-1.3.2.fpk` 完成安装。

> 打包结构（与社区可安装应用一致）：先 `tar` 出 `app.tgz`，再连同 `cmd`、`config`、`ICON*.PNG`、`manifest`、`wizard` 一起打进 fpk。不要把 `app/` 目录直接平铺进 fpk，否则安装器会报「解压 app.tgz 失败」。

> 若你已安装官方 `fnpack` 工具，也可直接 `fnpack build fn-usbcopy`。

### 方式二：直接用官方 fnpack（如有）

```bash
fnpack create fn-usbcopy -t native   # 或把本目录当作项目
fnpack build fn-usbcopy
```

安装完成后，飞牛桌面会出现「USB Copy 同步」图标，点击即可打开管理界面。

## 使用步骤

1. 打开「USB Copy 同步」。
2. 点击「+ 新建任务」。
3. **选择 U 盘**：在「识别 U 盘」下拉中直接点选当前已插入的设备（按 UUID 识别最稳定；也可选「任意 U 盘」）。若 U 盘已插入但下拉为空，先到「已连接 U 盘」页刷新，或点设备卡片上的「用此 U 盘新建任务」一键带入。
4. **配置文件夹配对**（可添加多对，仿 FreeFileSync 左右映射）：
   - 左侧「U 盘文件夹」点「浏览」，在目录选择器中进入 U 盘内目标目录（留空表示 U 盘根目录）。
   - 右侧「NAS 文件夹」点「浏览」，选择器先列出所有存储空间下的「我的文件」目录（如 `/vol1/1000`、`/vol2/1000`），选一个进入其子文件夹；自动识别不全时可在「设置 → 我的文件根目录」手动补充（多个用逗号分隔）。
   - 点击「+ 添加文件夹配对」可增加更多映射（例如把 `DCIM` 同步到 `…/照片`、`Docs` 同步到 `…/文档`）。
5. 选择复制模式、过滤器、冲突策略，按需开启「完成后弹出 U 盘」。
6. 保存。下次插入该 U 盘，即自动按各配对开始同步。

## 手机推送配置

1. 打开「设置」页，找到「手机推送」区块。
2. 勾选「启用手机推送」，并按需选择渠道（可多选）：
   - **PushPlus**（微信）：到 [pushplus.plus](https://www.pushplus.plus) 用微信扫码登录获取 Token，填入即可（在微信里接收）。
   - **SMTP 邮件**：填写邮箱 SMTP 服务器、端口（465=SSL / 587=STARTTLS）、账号与**授权码**（多数邮箱需开启 SMTP 服务并生成授权码，非登录密码）、收件人。
3. 点「发送测试推送」验证：手机上收到消息即配置成功（结果会显示 ✅/❌）。
4. 点「保存设置」。之后每次同步完成/失败都会自动推送。

> 说明：飞牛 App 自带通知默认只在飞牛 App 内显示，不进手机系统通知栏；通过上述渠道即可把同步结果直接推送到手机微信 / 邮箱。

也可在任务列表中点击「立即运行」手动触发（需对应 U 盘已插入并被 fnOS 挂载）。

## 目录结构

```
fn-usbcopy/
├── manifest                 # 应用元信息（appname/版本/端口等）
├── ICON.PNG / ICON_256.PNG  # 应用图标
├── app/
│   ├── usbcopy.py           # 主入口：启动监控线程 + Web 服务
│   ├── state.py             # 共享状态 / 配置持久化 / 日志
│   ├── usbmonitor.py        # USB 检测与插入监控
│   ├── syncengine.py        # 同步引擎（三种模式 / 过滤 / 冲突 / 弹出 / 日志明细）
│   ├── notify.py            # 手机推送（PushPlus / SMTP 邮件）
│   ├── server.py            # 内置 Web 服务（静态资源 + REST API）
│   ├── ui/config            # 飞牛桌面入口配置
│   ├── ui/images/           # 桌面图标
│   └── www/                 # 管理界面（index.html / app.js / style.css）
├── cmd/                     # 生命周期脚本（main/install/uninstall/upgrade/config）
├── config/
│   ├── privilege            # 运行权限（root，以便读写任意 NAS 文件夹）
│   └── resource
├── wizard/                  # 安装 / 卸载 / 更新 / 配置向导
├── tools/gen_icon.py        # 图标生成（纯标准库）
├── build.sh                 # 打包为 .fpk
└── README.md
```

## 配置与数据存放

- 任务配置：`{TRIM_PKGETC}/tasks.json`、`{TRIM_PKGETC}/settings.json`
- 运行日志：`{TRIM_PKGVAR}/logs/usbcopy.log`

（`TRIM_PKGETC` / `TRIM_PKGVAR` 为 fnOS 注入的环境变量，指向应用数据目录。）

## 注意事项 / 排错

- **桌面图标打不开 / 空白**：fnOS 桌面若以 HTTPS 提供，浏览器会拦截 HTTP 的 iframe。可改用浏览器直接访问 `http://<飞牛IP>:8765/`。
- **权限**：应用以 root 运行，以便读取 U 盘并写入任意 NAS 文件夹。若你的 fnOS 版本限制了第三方应用 root 权限，请将 `config/privilege` 的 `run-as` 改回 `package`，并预先把目标文件夹创建为应用可写。
- **U 盘未被识别**：确保 fnOS 已正常识别并**挂载**该外置设备（「外置设备」页面可见且已挂载）。本应用只处理已被系统挂载的分区；检测依赖 `lsblk` 输出的 `TRAN`/`removable` 与挂载点。
- **同步很慢 / 大文件**：当前使用 Python 原生复制（`shutil.copy2`，保留时间戳）。如需极速同步可后续接入 `rsync`，接口已在 `syncengine.py` 预留。
- **自动弹出后界面仍显示U盘**：设备列表每 5 秒自动刷新；若卸载失败（文件被占用等）设备会保留。可在「运行日志」查看「弹出U盘失败」记录，先关闭占用该U盘的程序再手动弹出。
- **查看日志**：应用中心对应应用的日志，或 SSH 登录后 `tail -f {TRIM_PKGVAR}/logs/usbcopy.log`。

## 与群晖 USB Copy 的差异

- 群晖以 DSM 套件形式提供图形化向导；本应用以 fnOS 第三方 fpk 形式提供同等核心能力（自动识别设备 + 三种模式 + 过滤 + 手机推送）。
- 暂未实现「硬件 Copy 按钮」触发（依赖特定机型）与「计划任务触发」（仅插入触发 + 手动触发）。如需可后续扩展。
